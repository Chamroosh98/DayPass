## 🚀 Что такое DayPass?

**DayPass** — это лёгкий, автоматизированный и модульный инструмент для роутеров на **OpenWrt**. Он объединяет управление сетью, прокси и умную маршрутизацию в одном месте.

Благодаря поддержке **Passwall**, **Multi-WAN**, **Guest Network** и **Clean IP**, он помогает сохранять стабильный доступ в интернет даже при сильной цензуре. От выбора лучших нод и разделения трафика до замены Cloudflare IP и применения готовых профилей маршрутизации — DayPass закрывает весь цикл.

Инструмент полностью совместим с обоими менеджерами пакетов современных версий OpenWrt:

- **OpenWrt 24.x** → `opkg`
- **OpenWrt 25.x** → `apk`

Пакеты скачиваются и устанавливаются автоматически с учётом версии OpenWrt и архитектуры процессора вашего роутера.

## ✨ Возможности

- 📦 **Ежедневная синхронизация пакетов (Daily Sync)**  
  Автоматическая загрузка обновлений необходимых пакетов без зависимости от официальных репозиториев OpenWrt (которые часто недоступны в странах под санкциями).

- 🔀 **Умное управление Multi-WAN**  
  Возможность одновременно объединять и управлять несколькими интернет-каналами: проводным и оптоволоконным (`WAN`), мобильным интернетом и USB-модемами (`USB WAN`), а также Wi-Fi в режиме клиента (`WWAN`) с помощью `mwan3`.

- 📡 **Изоляция и управление Wi-Fi**  
  Полное разделение конфигурации точки доступа (Access Point) и режима клиента (Client/Station), чтобы изменения в одном режиме не влияли на другой и не приводили к неожиданным отключениям Wi-Fi.

- 🔄 **Автоматическая синхронизация внутренней сети**  
  Автоматическое изменение IP внутренней сети, настройка диапазона DHCP и очистка устаревших записей из файла `dhcp.leases`.

- 🌐 **Совместимость с разными версиями OpenWrt**  
  Поддержка OpenWrt 24.x (`opkg`) и OpenWrt 25.x (`apk`) на более чем 9 архитектурах процессоров.

## 🚀 Установка

DayPass постоянно развивается, и в него добавляются новые функции для различных архитектур. Поэтому существуют две версии:

- **Стабильная** — меньше функций, но полностью надёжная.
- **Бета** — обновляется практически ежедневно и содержит больше возможностей, но может содержать ошибки.

> **‼️ Важно:** Бета-версия рекомендуется только тем, кто имеет базовое понимание темы, может самостоятельно отлаживать проблемы и сообщать о них. Начинающим пользователям лучше использовать стабильную версию.

---

### 🟢 Стабильная версия

Выполните следующую команду в терминале роутера:

```bash
wget -qO- https://chamroosh98.github.io/DayPass/install.sh | sh
```

Если на роутере уже установлен `curl`, можно использовать команду:

```bash
curl -sSL https://chamroosh98.github.io/DayPass/install.sh | sh
```

---

### 🟠 Бета-версия

Установка бета-версии:

```bash
wget -qO- https://chamroosh98.github.io/DayPass/beta/install.sh | sh
```

Или:

```bash
curl -sSL https://chamroosh98.github.io/DayPass/beta/install.sh | sh
```

> ⚠️ **Напоминание:** Бета-версия может содержать ошибки, поэтому рекомендуется только опытным пользователям или тем, кто любит тестировать новые возможности.

## 🔀 Multi-WAN и балансировка нагрузки

С помощью DayPass вы можете одновременно настраивать и управлять несколькими интернет-соединениями на роутере.

* **🌐 Проводной интернет (`Ethernet WAN`)**  
  Получение интернета от ADSL/VDSL-модема или оптоволокна через порт WAN (с использованием LAN-кабеля).

> 💡 **Разница между портами WAN и LAN**  
> * **Порт `WAN` (вход интернета):** роутер получает интернет от основного модема, оптоволокна или внешней антенны.  
> * **Порт `LAN` (выход интернета):** роутер раздаёт полученный интернет внутренним устройствам (компьютерам, телевизорам, вторым роутерам или коммутаторам).

* **📱 Интернет с телефона и USB-модема (`USB WAN`)**  
  Подключение Android-смартфонов, iPhone или 4G/5G USB-модемов к USB-порту роутера. DayPass поддерживает режимы CDC-Ethernet и RNDIS.

### 🔌 Роутеры с USB-портами (совместимые с USB WAN)

| Архитектура процессора | Модели с USB-портами | Количество и тип USB-портов |
| :--- | :--- | :--- |
| **`aarch64_cortex-a53`** | **Raspberry Pi:** 3B, 3B+, 4B<br>**FriendlyELEC:** NanoPi R2S, R4S, R5S<br>**GL.iNet:** Flint (GL-AX1800), Slate AX (GL-AXT1800)<br>**Xiaomi:** AX6000 | **Raspberry Pi:** 4× USB<br>**NanoPi:** 1–2× USB<br>**GL.iNet:** 1× USB 3.0<br>**Xiaomi:** 1× USB 3.0 |
| **`aarch64_cortex-a72/a76`** | **Raspberry Pi:** 4B, 5<br>**SBC:** Rockchip RK3399, RK3588 (NanoPi R6S, Orange Pi 5) | **Raspberry Pi:** 2× USB 3.0 + 2× USB 2.0<br>**Orange Pi / NanoPi:** 2–3× USB |
| **`arm_cortex-a7_neon-vfpv4` / `arm_cortex-a9`** | **Linksys:** EA8300, MR8300<br>**Netgear:** R7000, R7800, R8000<br>**ASUS:** RT-AC68U, RT-AC87U<br>**GL.iNet:** B1300 | **Linksys:** 1× USB 3.0 / 2.0<br>**Netgear / ASUS:** 1× USB 3.0 + 1× USB 2.0<br>**GL.iNet B1300:** 1× USB 3.0 |
| **`mipsel_24kc`** | **Xiaomi:** Mi Router 3G<br>**TP-Link:** Archer C7<br>**GL.iNet:** Mango (GL-MT300N-V2), Shadow (GL-AR300M) | **Xiaomi 3G:** 1× USB 3.0<br>**Archer C7:** 2× USB 2.0<br>**GL.iNet Mango/Shadow:** 1× USB 2.0 |
| **`x86_64` / `i386`** | **Мини-ПК и мини-серверы:** Intel N100, N5105, Protectli, Topton<br>**Виртуальные среды:** VMware, Proxmox (через USB Passthrough) | **Большинство имеют от 2 до 4 портов USB 3.0/2.0** |

> * **`USB WAN (Tethering)`**  
>   Общий термин для раздачи интернета с телефона или 4G/5G-модема на роутер через USB-кабель.  
> * **`RNDIS`**  
>   Стандарт Microsoft для эмуляции сетевой карты через USB. Чаще используется на старых Android-устройствах и некоторых USB-донглах.  
> * **`CDC-Ethernet`**  
>   Открытый стандарт Linux/POSIX. Обеспечивает более высокую скорость, меньшую задержку и лучшую стабильность на iPhone, современных Android-устройствах и новых модемах.

* **📡 Беспроводной интернет (`WWAN`)**  
  Получение интернета от другого роутера, модема или точки доступа и раздача его во внутреннюю сеть.

Эти соединения автоматически регистрируются в `mwan3` и предоставляют две основные возможности:

* **Failover**  
  При отключении одного из каналов трафик автоматически перенаправляется на другой путь.

* **Load Balancing**  
  Трафик распределяется между несколькими соединениями, чтобы одновременно использовать несколько интернет-каналов.

> **Важно:** Балансировка нагрузки **не означает**, что скорость одной загрузки будет равна сумме скоростей всех соединений. Трафик распределяется между доступными путями, а итоговая производительность зависит от типа соединений и настроек `mwan3`.

## 🌐 Управление и изоляция Wi-Fi

Одна из распространённых проблем OpenWrt возникает, когда роутер одновременно работает в режиме **точки доступа (Access Point)** и **клиента (Client)**. Изменение настроек одного режима может повлиять на другой и даже привести к отключению Wi-Fi.

DayPass решает эту проблему, полностью разделяя конфигурации этих двух режимов:

* Управление точкой доступа роутера для домашней сети на частотах 2,4 ГГц и 5 ГГц  
* Управление получением интернета через Wi-Fi (`WWAN` / режим Client) без изменения настроек точки доступа

## 🧼 Управление Clean IP для Cloudflare

Этот раздел предназначен для конфигураций, которые работают через **Cloudflare Worker / CDN**. Из-за жёсткой фильтрации оригинальный IP или домен может стать недоступным.

### ❓ Что делает этот инструмент?

- Выбирает повреждённую или нестабильную конфигурацию из сохранённых.
- Извлекает **порт** напрямую из share-ссылки.
- Проверяет список кандидатных IP-адресов на **том же порту**.
- Показывает доступные IP вместе с их задержкой (latency).
- Заменяет только поле **Address** на Clean IP.
- Полностью сохраняет важные параметры, такие как `SNI`, `Host` и `Path`.
- По желанию пользователя может импортировать обновлённую конфигурацию в Passwall.

## ⚙️ Ежедневное обновление пакетов

DayPass автоматически обновляет все необходимые пакеты каждый день. Процесс выглядит следующим образом:

1. 📥 Загрузка пакетов с **SourceForge**
2. 📦 Сортировка и подготовка пакетов по **9 архитектурам процессоров и 2 версиям OpenWrt**
3. 🌐 Публикация файлов на **CDN-сервисе jsDelivr**
